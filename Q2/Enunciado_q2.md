Questão 2 — Extração de Argumentos de Sentenças Jurídicas

Na Enter, queremos uma funcionalidade que recebe uma sentença judicial e extrai os principais argumentos usados pelo juiz. O objetivo é construir uma base de dados de argumentos jurídicos. Para cada nova sentença inserida na plataforma, queremos extrair e salvar esses argumentos de forma estruturada.

Desenhe uma solução para essa funcionalidade.
*
Sua resposta deve cobrir:

Que saída estruturada você salvaria. Exemplo: título do argumento, resumo, trecho citado, posição no documento, confiança e tipo de argumento.
Considerando que você use um LLM para essa tarefa, como reduziria o risco de o modelo inventar argumentos que não estão no texto.
Como lidaria com sentenças longas que não cabem inteiras no contexto do modelo
Como permitiria que um ser humano revise, edite ou rejeite argumentos extraídos.
Como mediria a qualidade da extração.
Como versionaria a extração caso o prompt, o modelo ou o schema mudem no futuro.
